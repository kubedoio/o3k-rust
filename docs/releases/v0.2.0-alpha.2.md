# O3K v0.2.0-alpha.2 — release candidate draft

This document is a release-candidate checklist, not a claim that the release
has shipped. The release gate remains blocked until real libvirt E2E, failure
recovery, clean Ubuntu and Debian installation artifacts, measured benchmark
data, and an approved human-review artifact bound to the candidate commit all
report the required status.

## What changed since v0.2.0-alpha.1

v0.2.0-alpha.2 is a re-certification of the changed runtime binaries — it adds
no new runtime features beyond what PR #614 changed after the alpha.1
publication (TAP-restore fix, recreate/revive product fixes, Debian bookworm
flavor handling). Everything else is the one-line installer milestone (#613,
already shipped) promoted to a first-class release asset:

- `install.sh` is now a first-class GitHub Release asset, exported
  byte-for-byte from `packaging/get-o3k.sh` (the single installer source) and
  recorded in the bundle manifest (`installer_sha256`, `installer_asset`);
  drift is gated by `cmp` at release-generation and archive time;
- the published installer is pinned to its own release version
  (`O3K_INSTALLER_VERSION=v0.2.0-alpha.2`): it installs exactly
  v0.2.0-alpha.2 by default and never consults a channel service;
- `get.o3k.io` is reduced to a convenience 302 redirect to the tagged GitHub
  Release asset; the Cloudflare Worker and `packaging/channels.yaml` remain
  only for optional future channel/version functionality and are not part of
  the trusted installation path;
- the direct alpha URL is
  `https://github.com/kubedoio/o3k-rust/releases/download/v0.2.0-alpha.2/install.sh`.

## Planned contents

- x86_64 `o3kd` and `o3k-compute` artifacts built on the Debian 12 (bookworm,
  glibc 2.36) release baseline so the same binaries execute on both advertised
  targets (Ubuntu 24.04 and Debian 12); the glibc floor is enforced by
  `packaging/check-glibc-baseline.sh` in `make-release.sh` and
  `verify-release-bundle.sh`;
- release assets: `install.sh`,
  `o3k-0.2.0-alpha.2-linux-x86_64.tar.gz`,
  `o3k-0.2.0-alpha.2-linux-x86_64.tar.gz.sha256`, `o3kd`, `o3k-compute`,
  `SHA256SUMS`, `sbom.spdx.json`, `manifest.json`;
- profile-aware installer, diagnostics, reset, purge, and uninstall commands;
- SBOM, dependency/license policy result, checksums, and provenance manifest;
- OpenStack CLI/clouds.yaml example and CirrOS walkthrough;
- compatibility matrix, security model, architecture, upgrade/rollback
  boundaries, and known alpha limitations.

No production, HA, full-OpenStack, security-group, Cinder, or CellHV-readiness
claim is made. Create a tag only after `packaging/release-gate.sh` reports
`status: ready` with `--source-commit` and `--human-review`; the gate does not
generate approval or substitute for the reviewer's judgment.
